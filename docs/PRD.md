# PRD — TO-DO ZONE (MVP)

용어는 [GLOSSARY.md](../GLOSSARY.md)를 따른다. 결정 근거는 [DECISIONS.md](DECISIONS.md)의 ID로 표시한다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 한 줄 정의 | 해야 할 일을 파스텔 Card로 만들어, Board 위에서 Status 사이로 옮기며 관리하는 개인용 웹앱 |
| 사용자 | 한국어로 할 일을 적는 개인 1명. 로그인 없이 자기 컴퓨터에서 실행한다 (D-002, D-006) |
| 해결할 문제 | 여러 Project에 흩어진 할 일을 한 화면에서 보고, 어디까지 했는지(Progress) 바로 알기 |
| 성공 기준 | 카드 추가 → Status 이동 → Done까지 마우스만으로 3번 이내 조작. 새로고침 후에도 데이터 유지 |

## 2. MVP 기능

각 기능은 **시나리오**와 **수용 기준**(체크 가능한 조건)으로 정의한다. 수용 기준은 TEST-PLAN(step10)에서 테스트로 옮긴다.

### F1. Board 보기 (D-010, D-014)
**시나리오:** 사용자가 앱을 열면 Todo / Doing / Done 세 열에 모든 Card가 보인다.
- [ ] Board에는 Todo, Doing, Done 3개 열이 이 순서로 보인다
- [ ] 각 Card는 소속 Project의 색으로 표시된다
- [ ] 각 열 제목 옆에 그 열의 Card 수가 보인다
- [ ] Card가 없는 열에는 빈 상태 안내 문구가 보인다
- [ ] Card는 내용에 따라 크기 단계(Focus / L / M / S / Done)로 자동 표시된다 (D-060)
- [ ] 각 Card에 소속 Project의 아이콘이 보이고, Due date에는 상태 아이콘(오늘 / 지난 마감 / 날짜)이 붙는다 (D-062, D-063)
- [ ] 화면 위쪽 요약 문장에 진행 중·오늘 마감·지난 마감 Card 수가 보인다. 모두 0이면 "오늘은 여유로운 날이에요." (D-064)

### F2. Card 만들기 (D-018, D-013)
**시나리오:** 사용자가 Todo 열의 "+ New card"를 누르고 "자료구조 과제 제출"을 입력한 뒤 Enter를 누른다.
- [ ] 모든 열 맨 위에 "+ New card"가 있다
- [ ] 제목을 입력하고 Enter를 누르면 Card가 그 열의 **맨 위**에 생긴다
- [ ] 한글 조합 중(`isComposing`)에 누른 Enter로는 Card가 생기지 않는다 (마지막 글자 중복 방지)
- [ ] 빈 제목이나 공백만 있는 제목으로는 Card가 생기지 않는다
- [ ] 제목은 100자를 넘게 입력할 수 없다 (D-031)
- [ ] Project 필터가 켜져 있으면 그 Project에, 꺼져 있으면 Inbox에 들어간다
- [ ] Esc를 누르면 입력이 취소된다

### F3. Card 상세 보기·수정 (D-011, D-017)
**시나리오:** 사용자가 Card를 클릭해 오른쪽 상세 패널에서 메모와 Due date를 입력한다.
- [ ] Card를 클릭하면 상세 패널이 열린다
- [ ] 제목, 메모, Due date, Project, Status를 수정할 수 있다
- [ ] 제목을 비운 상태로는 저장되지 않는다
- [ ] 제목은 100자, 메모는 2,000자를 넘을 수 없다 (D-031)
- [ ] Due date는 날짜만 고를 수 있고, 지울 수도 있다
- [ ] 바꾼 내용은 새로고침 후에도 유지된다

### F4. Card 옮기기 (D-013, D-021)
**시나리오:** 사용자가 Todo의 Card를 Doing 열로 드래그한다.
- [ ] 데스크톱에서는 Card를 드래그해 다른 열로, 또는 같은 열 안의 다른 위치로 옮길 수 있다
- [ ] 놓은 위치가 그대로 저장되고 새로고침 후에도 유지된다
- [ ] 모바일(375px)에서는 상세 패널의 Status 변경으로 옮길 수 있다
- [ ] Status 변경으로 옮긴 Card는 새 열의 맨 위에 놓인다

### F5. 완료 (D-012, D-019)
**시나리오:** 사용자가 Card를 Done 열로 옮기면 그 Card는 완료된 것이다.
- [ ] Card의 완료 여부는 Status가 Done인지로만 결정된다
- [ ] Done 열은 접고 펼 수 있다
- [ ] Done Card는 모두 표시된다(개수 제한 없음)

### F6. Due date와 Overdue (D-017)
**시나리오:** 마감일이 어제인 Card가 Doing에 있으면 마감일이 경고색으로 보인다.
- [ ] Due date는 "오늘", "내일", "어제", 그 외는 "10월 9일 (목)" 형식으로 표시된다
- [ ] Done이 아니고 Due date가 오늘보다 이전이면(Overdue) 경고색으로 표시된다
- [ ] Done Card는 Due date가 지나도 경고색이 아니다

### F7. Card 삭제 (D-015)
- [ ] 상세 패널에서 Card를 삭제할 수 있다
- [ ] 삭제 전에 확인 창이 뜨고, 확인을 눌러야만 삭제된다
- [ ] 삭제된 Card는 복구할 수 없다

### F8. Project 관리 (D-005, D-016)
**시나리오:** 사용자가 "학교" Project를 만들고 라벤더 색을 고른다.
- [ ] Project를 만들고, 이름·색(4색 중 하나)·아이콘(25개 중 하나)을 바꿀 수 있다 (D-042, D-062)
- [ ] 새 Project의 색은 4색을 순서대로 돌아가며, 아이콘은 `folder`로 자동 지정된다
- [ ] Project 이름은 앞뒤 공백을 제거하고 1~30자다 (D-065)
- [ ] 이미 있는 이름으로는 만들거나 바꿀 수 없다
- [ ] 여러 Project가 같은 색을 쓸 수 있다
- [ ] Project를 삭제하면 확인 창이 뜨고, 그 Project의 Card는 Inbox로 옮겨진다
- [ ] Inbox는 삭제하거나 이름을 바꿀 수 없고, 색(크림)과 아이콘(inbox)은 고정이다 (D-032, D-062)
- [ ] Project는 Inbox 포함 20개까지 만들 수 있다. 20개일 때는 만들기 버튼이 비활성화되고 이유가 표시된다 (D-034)

### F9. Project 필터와 Progress (D-014, D-020)
**시나리오:** 사용자가 위쪽 Project 줄에서 "학교"를 눌러 학교 Card만 본다.
- [ ] Board 위쪽에 모든 Project가 가로로 나열된다 (Inbox 포함)
- [ ] 각 Project에 Progress 바와 "Done 수 / 전체 수"가 표시된다. Card가 0장이면 0%
- [ ] Project를 누르면 Board에 그 Project의 Card만 보인다
- [ ] 필터는 한 번에 하나만 켜지고, 같은 Project를 다시 누르면 해제된다 (D-033)

### F10. 분기 아카이브 (D-070 ~ D-073, D-075)
**시나리오:** 9월 30일에 끝낸 Card는 10월 1일부터 Board의 Done 열에서 빠지고, 회고 대시보드의 2026 Q3에서 보인다.
- [ ] Card가 Done에 들어가면 완료 시각이 기록되고, Done에서 나가면 지워진다
- [ ] Board의 Done 열에는 완료 시각이 이번 분기인 Card만 보인다
- [ ] 열 개수와 Project Progress는 Board에 보이는 Card 기준이다
- [ ] 아카이브된 Card는 "다시 열기"로 Todo 맨 위로 돌아온다

### F11. Quarterly Review 대시보드 (11-7, D-074)
**시나리오:** 사용자가 분기를 골라 그 분기에 끝낸 일을 Project별로 돌아본다.
- [ ] 분기를 고를 수 있다 (기록이 있는 분기 + 이번 분기)
- [ ] 그 분기에 끝낸 Card 수가 크게 보인다
- [ ] Project별 완료 수가 Project 색 막대로 보인다
- [ ] 끝낸 Card 목록이 Project별로 묶여 완료 날짜와 함께 보인다

## 3. 공통 요구사항

| 영역 | 요구사항 | 근거 |
|---|---|---|
| 언어 | 타이틀·열 이름·주요 버튼은 영어, 안내·오류 문장과 날짜는 한글 | D-007 |
| 한글 | 본문 행간 1.5, `word-break: keep-all`, Card 제목은 3줄 넘으면 말줄임 | D-007 |
| 테마 | 채운 디자인 언어: 올리브 블랙 캔버스 + 색 Card, 그림자·기울기·점선 없음 | D-008, D-056, D-061 |
| 기기 | 데스크톱 우선(1024), 모바일 375px 지원 | D-021 |
| 저장 | 모든 변경은 서버(SQLite)에 저장, 새로고침 후 유지 | D-006, D-026 |
| 실행 | 로컬 전용, 로그인 없음 | D-006 |
