# 서버와 DB를 두되 로그인은 두지 않는다 (로컬 전용)

데이터는 서버와 DB에 저장하지만, 사용자가 1명이라 회원가입과 로그인을 두지 않는다. 서버를 두는 이유는 구현 계획(step11)에 backend와 connect 단계가 있기 때문이다. 로그인이 없으므로 서버 주소를 아는 사람은 누구나 데이터에 접근할 수 있다. 따라서 이 앱은 **사용자의 컴퓨터에서만 실행하는 것을 전제**로 하고, 외부 공개 배포는 하지 않는다.

## Considered Options

- 브라우저 저장(localStorage)만 사용: 가장 단순하지만 step11의 backend/connect 단계와 맞지 않는다.
- 회원가입·로그인 포함: 인증, 세션, 비밀번호 처리까지 범위가 크게 늘어난다.

## Consequences

- 외부에 배포하려면 먼저 인증을 추가하는 결정이 필요하다.
