# 분기 아카이브는 저장하지 않고 완료 시각으로 계산한다

Done Card는 분기가 지나면 Board에서 빠지고 회고 대시보드로 간다. "아카이브됨" 상태를 DB에 따로 저장하면 분기가 바뀌는 순간 누군가(예약 작업)가 상태를 바꿔 줘야 하고, 그 작업이 빠지면 데이터가 어긋난다. 그래서 Card가 Done에 들어간 시각(`completed_at`)만 기록하고, 이번 분기인지는 화면을 그릴 때 사용자 컴퓨터의 날짜로 계산한다. Done에서 나가면 `completed_at`을 지워서 "Done이면 완료 시각이 있다"를 DB 제약(CHECK)으로 지킨다.

## Considered Options

- `archived` 표시 열 + 분기 시작 시 일괄 변경: 예약 작업이 필요하고, 서버가 꺼져 있던 동안의 분기 전환을 놓칠 수 있다.
- Card마다 소속 분기를 지정(분기 계획형 Board): 할 일이 분기를 넘어 이어지는 흐름과 맞지 않는다 (D-070).

## Consequences

- 아카이브된 Card도 `status = 'done'`이고 Done 순번을 가진다. Board는 이번 분기 Card만 보여 주고, 끼워 넣는 위치는 기존 규칙(보이는 Card 바로 뒤, DATA-MODEL 4)을 그대로 쓴다.
