# 카드 1장은 할 일 1개다 (Trello 구조)

참고 대상 두 서비스의 카드 의미가 서로 반대다. Trello에서 카드 1장은 할 일 1개이고, Morrow에서 카드 1장은 날짜별 할 일 묶음(체크리스트)이다. "내 할 일을 카드로 만든다"는 목표에 맞춰 Trello 구조를 택했다. 그래서 카드는 열 사이를 옮길 수 있는 독립 단위다. Morrow에서는 시각 형식(다크 캔버스, 파스텔 카드, 프로젝트 줄)만 가져온다.

## Considered Options

- 카드 = 날짜별 묶음 (Morrow): 하루 단위 회고에는 좋지만, 카드 하나를 독립적으로 옮기거나 상태를 바꿀 수 없다.
