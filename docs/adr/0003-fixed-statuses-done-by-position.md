# Status는 Todo/Doing/Done 3개로 고정하고, 완료는 Done 위치로만 판단한다

Trello처럼 사용자가 열을 자유롭게 만들 수 있게 하지 않는다. Status를 Todo, Doing, Done 3개로 고정하고, 카드의 완료 여부는 별도의 완료 표시 없이 **Status가 Done인지로만** 판단한다. 열을 자유롭게 바꿀 수 있으면 앱이 "완료"를 알 수 없어 Project 진행률을 계산할 수 없다. 완료 표시를 따로 두면 "Doing 열에 있는데 완료됨" 같은 모순 상태가 생긴다.

## Consequences

- 카드에 체크박스를 두더라도 "누르면 Done으로 이동"하는 단축 버튼일 뿐, 별도 데이터가 아니다.
- 열을 추가하거나 이름을 바꾸는 기능을 넣으려면 이 결정을 먼저 다시 검토해야 한다.
